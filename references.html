REPRODUCIBILITY

How to recreate the figures

1. Obtain the official trace from Alibaba and document the selected file/subset.

2. Install requirements.txt, run the analysis script, then publish the generated chart assets with this website.

pip install -r requirements.txt
python analysis/analyze.py \
  --input path/to/server_usage.csv

The script records selection rules, valid-row counts and figure metadata. Review all findings before presenting.
