SCHEMA / 2017 SERVER USAGE

Eight fields to inspect

Column (schema)MeaningAnalytical use
timestampSeconds relative to trace startTime coverage; time series
machineIDMachine identifierBetween-machine comparisons
util:CPUMachine CPU utilization (0–100 scale)CPU distribution and trends
util:memoryMachine memory utilization (0–100 scale)Memory distribution and trends
util:diskMachine disk utilizationContext, optional
load1Linux 1-minute load averageSupplementary OS interpretation
load5Linux 5-minute load averageSupplementary OS interpretation
load15Linux 15-minute load averageSupplementary OS interpretation

Field order follows Alibaba's 2017 schema. Source CSV files are headerless. Utilization is on a 0–100 scale; load average is a separate, non-percent metric.
